# Artist Site

A minimalist portfolio website for an artist. Built as a full-stack TypeScript monorepo — Express + Prisma backend, React + Vite frontend.

# Project structure

artist-site/
¬backend/ -node.js + Express + Typescript + Prisma
¬prisma/
¬schema.prisma - database schema
¬seed.ts -sample data dev

## Prerequisites

- Node.js 20+
- PostgreSQL running locally (or a connection string from Railway/Neon/Supabase)

## Getting started

# 1. Clone and install

git clone <https://github.com/Esther-FaBer/Artist-site>
cd artist-site

# Install backend dependencies

cd backend && npm install
